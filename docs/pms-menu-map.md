## 觀察

1. **跨模組共用功能**：綜合櫃檯(PMS0210020)出現在接待/出納/夜核；住客歷史/交辦事項等也跨模組出現。同一 prgId 代表同一頁面，不同模組入口只是選單捷徑。
2. **報表頁共用 prgId**：每個模組的報表集中在少數幾個 prgId（如 PMS01R1~R3），同一頁面內靠 tab/參數切換不同報表。
3. **實際獨立頁面數**遠少於 284（去重後約 80~90 個獨立 prgId）。
4. **設定模組最大**（66 項），但多為簡單 CRUD 頁面，結構相似度高。
